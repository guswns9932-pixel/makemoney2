# Git 작업 규칙

Claude Code가 실제 저장소를 직접 수정하는 단계이므로, 역할 규칙과 별개로 아래 Git 안전규칙을 따른다.

- 작업 시작 전 `git status`로 현재 변경사항을 확인한다.
- 기존 변경사항(스테이징 여부 무관)을 임의로 삭제하지 않는다.
- `git push --force`(force push)를 사용하지 않는다.
- `git reset --hard`를 임의로 실행하지 않는다.
- `main` 브랜치에 직접 병합하지 않는다. 작업은 별도 브랜치에서 진행하고 병합 여부는 사용자/GPT 승인을 따른다.
- 사용자 파일이나 기존 코드를 작업 범위 밖에서 임의로 삭제하지 않는다.
- 비밀키(API Key), 환경변수, 개인정보가 포함된 파일은 절대 commit하지 않는다. `.gitignore`로 사전 차단되어 있는지 매번 확인한다.
- 작업 범위 밖 파일은 원칙적으로 수정하지 않는다 (수정이 불가피하면 결과보고의 "변경사항"에 명시).
- 작업 종료 시 변경된 파일 목록을 `[CLAUDE RESULT]`의 "산출물" 항목에 명시한다.
- GPT 검수(PASS) 전에는 Release/Final 태그를 생성하지 않는다.
