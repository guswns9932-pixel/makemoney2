# [프로젝트 브리프] Tool01 Demo

- 프로젝트명: Tool01 — 수료증·상장·확인서·증명서 대량생성
- 주제: Excel/CSV 명단과 PowerPoint 템플릿을 이용해 개인별 PDF 문서를 일괄 생성하는 Windows 로컬 자동화 Tool
- 현재 단계: Validation용 Demo 구현
- 타겟 대상: 소규모 민간 교육기관, 교육대행사, 직무교육업체 등 1~20명 규모의 조직 중 월 1회 이상, 회당 약 30~500건의 수료증·상장·확인서·증명서를 반복 생성하는 실무 담당자
- 고객이 겪는 문제: Excel 명단을 보면서 PowerPoint/문서 템플릿의 이름, 수료번호, 과정명, 수료일, 기관명 등을 건별로 바꾸고 PDF로 저장하는 반복작업 때문에 시간이 오래 걸리며 오타, 누락, 잘못된 파일명, 중복 저장 등의 오류가 발생한다.
- 핵심 가치 제안: 코드, VBA, Apps Script, Mail Merge 설정 없이 `명단 파일 선택 → PPTX 템플릿 선택 → Preview → PDF 일괄생성`만으로 반복 문서 발급 업무를 끝내게 한다.
- 수익화 방식: Tool 단품 판매 + 기존 Tool을 기반으로 한 Custom Template Setup/맞춤 자동화
- 예상 판매가격:
  - Validation 판매가격: 29,000원
  - Custom Template Setup: +79,000원 (총 108,000원 가설)
  - Validation 통과 후 목표 단품가격: 39,000원
  - 가격 변경은 사용자/GPT 승인 없이 임의 적용하지 않는다.
- 필요한 산출물:
  - Windows에서 실제 실행 가능한 Demo 프로그램
  - Demo 소스코드
  - 샘플 `교육생명단.xlsx`
  - 샘플 `수료증_Template.pptx`
  - Demo 실행 가이드
  - 생성 결과 샘플 PDF
  - 테스트 결과 및 `[CLAUDE RESULT]`
- 제약사항/톤앤매너:
  - Windows 로컬 실행
  - Excel과 PowerPoint를 사용하는 일반 사무환경을 Baseline으로 한다.
  - 사용자는 코드나 스크립트를 입력하지 않는다.
  - 서버/Web/Cloud/API/Login/DB가 없어야 한다.
  - 기존 원본 Excel/CSV/PPTX 파일은 수정하지 않는다.
  - Demo 단계에서는 최종 설치 프로그램 패키징까지 하지 않는다.

## Validation Package 확정 내용

### 1. Primary ICP

- 소규모 민간 교육기관
- 교육대행사
- 직무교육업체
- 조직 규모 약 1~20명
- 월 1회 이상 문서 발급 업무 존재
- 1회 처리량 약 30~500건

### 2. 핵심 Pain

현재 작업 흐름의 대표적인 문제는 다음과 같다.

1. Excel 명단을 한 줄씩 확인한다.
2. PowerPoint 또는 문서 템플릿을 열어 이름/번호/과정명/날짜 등을 수정한다.
3. 개인별 PDF로 저장한다.
4. 파일명을 다시 확인한다.
5. 수십~수백 명에게 같은 과정을 반복한다.

그 결과 다음 비용이 발생한다.

- 반복 입력 시간
- 이름/번호/날짜 오입력
- 일부 인원 누락
- 잘못된 파일명
- 기존 파일 덮어쓰기
- 작업 후 재검수 시간

### 3. 핵심 가치

**Excel/CSV 명단 + PPTX 템플릿만 준비하면 개인별 PDF를 자동으로 일괄 생성한다.**

사용자는 VBA, 코딩, Apps Script, Mail Merge 규칙을 배우거나 수정할 필요가 없다.

### 4. 핵심 차별점

- 코드 입력 없음
- 스크립트 수정 없음
- 별도 계정 없음
- 클라우드 업로드 없음
- 기존 Excel/PowerPoint 중심의 사무업무 흐름 유지
- `{{필드명}}`과 Excel/CSV 컬럼명을 기준으로 단순 자동매핑
- 결과 파일명과 누락 필드를 생성 전에 검증

### 5. Demo 기준 대표 Use Case

`교육생명단.xlsx` 100행을 `수료증_Template.pptx`에 적용하여 100개의 개인별 수료증 PDF를 생성한다.

샘플 데이터 컬럼:

- 수료번호
- 이름
- 과정명
- 수료일
- 기관명

샘플 PPTX Placeholder:

- `{{수료번호}}`
- `{{이름}}`
- `{{과정명}}`
- `{{수료일}}`
- `{{기관명}}`

기본 결과 파일명:

`{수료번호}_{이름}_수료증.pdf`

## Demo 시나리오

### 준비 파일

- `교육생명단.xlsx`: 100행
- `수료증_Template.pptx`: 1개
- 빈 결과 폴더

### 고객에게 보여줄 흐름

1. Tool01 실행
2. `교육생명단.xlsx` 선택
3. `수료증_Template.pptx` 선택
4. 출력 폴더 선택
5. 자동매핑 결과를 확인하고 `Preview` 실행
6. 첫 번째 수료증 결과 확인 후 `PDF 일괄생성` 실행
7. 진행률과 성공/실패 건수 확인
8. 결과 폴더를 열어 2~3개 PDF와 파일명을 확인

사용자 핵심 조작은 **파일 선택 → Preview → 일괄생성** 중심으로 최대 6단계 수준을 목표로 한다.

### Demo 성공 기준

- 샘플 100행 기준 100/100 PDF 생성
- 데이터 매핑 오류 0건
- 파일명 오류 0건
- 한글 깨짐 0건
- 원본 파일 변경 0건
- 코드/스크립트 수정 없이 완료
- 대표 환경 기준 전체 생성 목표시간 2분 이내

실제 성능은 PC/Office 환경 영향을 받으므로 직접 측정하지 못한 경우 `[CLAUDE RESULT]`에 `미검증: 실제 Windows 환경에서 확인 필요`라고 기록한다.

Demo를 타겟 잠재고객 10곳에 제시한 뒤 다음 중 하나를 달성하면 Full MVP 진행을 `GO` 판단 대상으로 올린다.

- 29,000원 유료 Pilot 2건 이상
- Custom Template Setup 유료 요청 1건 이상

이 사업 판단은 GPT/사용자 영역이며 Claude가 임의로 변경하지 않는다.
